# MeroSchool

A React + Vite application for MeroSchool, designed with Tailwind CSS, Lucide icons, and React Router.

## Project Structure

```text
website/
├── index.html                 # Root HTML shell & meta tags
├── public/                    # Static assets & metadata
├── src/
│   ├── assets/                # App images and logos
│   ├── components/            # Layout, SEO, and UI components
│   ├── config/                # Contact configuration
│   ├── context/               # Theme & Language context providers
│   ├── data/                  # Knowledge base and localized data
│   ├── pages/                 # Route pages (Home, Features, About, etc.)
│   ├── App.tsx                # App root provider
│   ├── main.tsx               # Entry point
│   ├── router.tsx             # React Router setup
│   └── index.css              # Global Tailwind styling
├── package.json
├── tsconfig.json
└── vite.config.ts
```

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
